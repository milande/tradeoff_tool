How to use the Trade-Off Tool

A structured way to compare options when multiple things matter — no gut feel, just weighted evidence.

① Criteria

List what matters to you (e.g. Cost, Speed, Quality). Then compare each pair: which is more important? The tool converts your answers into percentage weights.

② Solutions

Add the options you're deciding between. For each criterion, rate every solution from 0 (worst) to 4 (best). The weighted ranking updates instantly.

③ Sensitivity

Drag the white line on any criterion bar to explore: "What if this mattered more — or less?" The ranking updates live. Color segments show which solution leads at each weight, and breakpoint labels mark where the winner switches.

↓ / ↑ Data

Your session auto-saves in the browser. ↓ HTML exports a fully self-contained file with your data baked in — open it anywhere, embed it in Confluence, or share it. ↓ JSON exports just the data for re-importing. ↑ Import loads a JSON file. New clears everything.

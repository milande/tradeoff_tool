How to use the DecisionLab

A structured way to compare options when multiple things matter — no gut feel, just weighted evidence.

① Criteria

List what matters to you (e.g. Cost, Speed, Quality). Then compare each pair: which is more important? The tool converts your answers into percentage weights.

② Solutions

Add the options you're deciding between. For each criterion, rate every solution from 0 (worst) to 4 (best). The weighted ranking updates instantly.

↓ / ↑ Data

Your session auto-saves in the browser. ↓ HTML exports a fully self-contained file with your data baked in — open it anywhere, embed it in Confluence, or share it. ↓ JSON exports just the data for re-importing. ↑ Load loads a JSON file. New clears everything.

⚡ Pro Mode

Toggle ⚡ Pro in the tab bar to unlock two advanced features:

Fine-tune Weights — after the pairwise comparison sets your weights, you can manually nudge individual percentages. The others adjust proportionally so everything stays at 100%. A Custom badge appears when weights have been overridden; ↺ Reset to pairwise reverts them.

Sensitivity Analysis — drag the white marker on any criterion bar to explore "What if this mattered more or less?". The ranking updates live. Colored segments show which solution leads at each weight level, and labels mark the exact % where the winner switches.
